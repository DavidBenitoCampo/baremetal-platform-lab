# 10-inch Modular Rack

This directory will contain the mechanical design for the project's custom 10-inch rack.

## Design Goals

- 10-inch rack format
- Approximately 12U target capacity
- Modular device-independent frame
- Replaceable device trays
- Raspberry Pi 5 + NVMe tray
- Switch and firewall trays
- Rear cable management
- Front-to-back airflow
- Heat-set inserts and standard fasteners
- Printable on a Prusa CORE One L

## Planned Layout

```text
U12  Patch panel
U11  Managed switch
U10  Router / firewall
U09  Raspberry Pi module
U08  Raspberry Pi / compute module
U07  Compute
U06  Compute
U05  Future expansion
U04  NAS
U03  NAS
U02  Power / cooling
U01  Power / cooling
```

The final layout will not be frozen until networking and storage hardware dimensions are known.
