# ADR 002 SSD storage

Status: accepted project design. Mount verification pending.

Boot Ubuntu Server ARM64 from the existing 512 GB SATA SSD through the USB adapter.
Place root, K3s metadata, images, and local monitoring data on this SSD.
Keep the microSD card spare after SSD boot works.

Verify root with `findmnt` and `lsblk`. The adapter alone does not prove placement.
The SSD adds no independent redundancy. Another computer disk holds the encrypted
K3s state backup. Access to this independent destination needs confirmation.
