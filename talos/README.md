# Talos

Talos Linux machine configuration, patches, and non-secret cluster configuration belong here.

Never commit generated secrets, `talosconfig`, private keys, or credentials.

## Layout

- `patches/pi5.yaml` — hardware patch shared by every Pi 5 machine (install
  disk/image via the `rpi_5` Image Factory overlay, time servers).
- `patches/ephemeral-ssd.yaml` — puts the `EPHEMERAL` volume (`/var`, etcd,
  container images) on the external USB SSD instead of the boot microSD.
  Must be applied at first `apply-config`.
- `patches/controlplane.yaml` — control-plane-role patch for the Milestone 1
  single-node cluster (hostname, certSANs, scheduling).
- `secrets/` — generated by `scripts/bootstrap-talos.sh`; contains real
  machine configs, `talosconfig`, and PKI material. Gitignored, never commit.

See [`docs/runbooks/bootstrap-talos.md`](../docs/runbooks/bootstrap-talos.md)
for how these patches are combined and applied.
